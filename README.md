# Audiolab
Building the foundations of a continuous-pitch audio processing engine for any musical tuning or notation system.


### Legacy Functions 
#### autorepitch
Generates pitch-shifted audio samples of a given audio
file in a specified range, for the creation of sample-based soundfont files.
